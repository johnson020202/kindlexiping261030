# 内容与来源

## 范围

首版 100 部：

- **70 部中国古典与人文作品**：原文来自 `garychowcmu/daizhigev20` 的 TXT 底本，经 OpenCC `t2s` 转为简体；保留底本 URL 与 SHA-256。
- **30 部莎士比亚戏剧**：朱生豪（1912–1944）译本，来自 `bzy-debug/shakespeare` 的中文合集，保留作品 ID、文本 URL 与 SHA-256。

这不是“100 部西方小说”。选择原因是：现代中文译本通常仍受译者著作权保护，不能在公开仓库中直接批量复制；本版只用可核对的公版/古典文本。

## 摘抄规则

1. 只取原文片段，不让语言模型生成、扩写或改写。
2. 在同一段原文内按自然句界组合，目标约 150 字，允许 70–260 字。
3. 过滤目录、版本说明、校勘者文字、HTML 标记和字体不支持的私用区字符。
4. 全库 5,000 条互不重复；同一本 50 条。
5. `sourceExcerpt` 保留简繁转换前原文；`text` 为简繁转换后的显示文本；`chapter` 为最近的章节标题（无标题时为“正文”）。
6. 底本 SHA-256 可对照 `content/books.json` 的 `source.sha256` 复核。

## 版权边界

- 古籍原文本身多已进入公有领域，但**数字底本的整理、标点、校注可能另有权利**。本项目只保留摘抄片段，不对底本主张版权，也不随源码发布完整底本。
- 朱生豪译文于中国著作权法下通常已进入公有领域；其他司法辖区状态需分别核对。
- 发布、商用或大规模再分发前，请自行核对来源站点条款、底本编者与当地法律。
- 如权利人提出合理异议，应替换对应条目，而不是把有争议内容标成“已授权”。

## 可复现

```sh
python3 tools/build_content.py
```

脚本重新获取底本并写出 `content/books.json` 与 `content/import-skipped.json`；不足 50 条或含不支持字形的作品会跳过并记录原因。不会用重复句子补足数量。
