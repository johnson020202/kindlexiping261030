# 越狱与安装

## 先确认设备

在 Kindle 搜索框输入 `;711` 可查看固件信息（部分机型有效）；也可连接电脑读取 `system/version.txt`。本项目当前连接设备记录为：

- 屏幕：1072 × 1448 灰度
- 固件：5.16.2.1.1
- 触控：`/dev/input/event1`
- 已有 root 脚本入口：搜索框 `;log runme` 执行 `/mnt/us/RUNME.sh`

## 越狱方式

本项目**不重新打包或分发越狱漏洞**，也不建议在未确认机型/固件时升级或重刷。请按官方维护的路线操作：

1. 在 [KindleModding 越狱总入口](https://kindlemodding.org/jailbreaking/) 核对你的机型、固件与当前可用方案。
2. 现代固件通常先完成 hotfix，再安装 KPM / Scriptlet；旧方案 KUAL 已过时。
3. 本项目通过已有 hotfix 的 `;log runme` 入口安装运行时，不依赖 KUAL、MRPI 或 KOReader。
4. 越狱有风险，可能失去保修或导致设备不可用；操作前自行备份书籍与文档。不要把本项目的“安装成功”理解为“越狱一定安全”。

参考：

- [KindleModding jailbreaking](https://kindlemodding.org/jailbreaking/)
- [WinterBreak](https://github.com/KindleModding/WinterBreak)
- [Hotfix](https://github.com/KindleModding/Hotfix)
- 屏保引擎 [kindle-custom-screensaver](https://github.com/chengandre/kindle-custom-screensaver)（MIT）

## 安装步骤

### A. 电脑脚本安装（推荐）

```sh
./tools/install_kindle.sh
```

脚本会：

1. 检查 `/Volumes/Kindle`；
2. 备份现有 `RUNME.sh` 到 `RUNME.before-kindlexiping.sh`；
3. 复制 `extensions/kindlexiping261030/`、`documents/栖息*.sh`；
4. 安装一次性的启用入口 `RUNME.sh`；
5. 同步文件并提示安全弹出。

### B. 手动安装

解压发布包，把 `extensions/` 和 `documents/` 合并复制到 Kindle 根目录。然后备份并替换根目录 `RUNME.sh` 为发布包中的 `RUNME.sh`。

### C. 在 Kindle 上启用

安全弹出后，在 Kindle 搜索框输入：

```text
;log runme
```

回车后设备会：

- 把可执行文件复制到 `/var/tmp/kindlexiping-bin`；
- 启动屏保守护进程；
- 在 `/mnt/us/extensions/kindlexiping261030/install.log` 写入结果。

回到主页，按电源键休眠，锁屏应为当天摘录。若没有变化，查看上述日志。

## 日常使用

- **换上一句 / 下一句**：书库中打开「栖息 · 翻阅」，按屏幕左半/右半切换，底部中间退出。
- **重新启用锁屏**：打开「栖息 · 开启每日锁屏」。
- **恢复原厂锁屏**：打开「栖息 · 关闭并恢复」。
- **重启后**：上游引擎不设置开机自启；再次执行 `;log runme` 即可。
- **完全卸载**：先关闭，再删除 `/mnt/us/extensions/kindlexiping261030/`、`/mnt/us/documents/栖息*.sh`，恢复 `RUNME.before-kindlexiping.sh`。

## 已知限制

- 当前固件 5.16.2.1.1 低于上游屏保引擎声明的 `>= 5.16.3` 起测范围，必须在真机验证后确认；若守护进程无法接管 renderer，关闭脚本仍可恢复原厂行为。
- 带 Special Offers 的广告版 `ad_screensaver` 未在上游完整验证。
- Kindle 原生锁屏层不支持可靠触控；翻句在解锁后的独立页面完成，不伪装成锁屏可点击。
- 原生 reader 的触控坐标由设备 ABS 范围归一化到 1072×1448，若你的机型分辨率不同需重新适配。
- 睡眠期间不保持进程，也不联网；锁屏时间在进入休眠的瞬间写入。
